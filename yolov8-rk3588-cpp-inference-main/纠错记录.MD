### 1. 摄像头分辨率 / 窗口大小统一 720p

**文件：**
- `run.sh` dual 分支
- `src/main.cc`

**问题：** 双摄模式下两个摄像头默认分辨率不一致，窗口大小也不统一。

**修改：**

`run.sh` — dual 模式启动前用 v4l2-ctl 统一协商 720p MJPG：
```sh
v4l2-ctl -d 0 --set-fmt-video=width=1280,height=720,pixelformat=MJPG
v4l2-ctl -d 2 --set-fmt-video=width=1280,height=720,pixelformat=MJPG
```

`main.cc` — 双摄窗口 resize 到 1280×720：
```cpp
cv::resizeWindow("Cam0", 1280, 720);
cv::resizeWindow("Cam1", 1280, 720);
```

> 摄像头 0 和 2 需支持 1280×720 MJPG。若分辨率不足会协商失败，需确认硬件能力。

### 2. 帧率打印改为每 30 帧输出一次

**文件：** `src/main.cc`

**问题：** 原来只在程序结束时打印平均帧率，运行时无法观察实时性能。

**修改：** 双摄各线程独立统计，每处理 30 帧打印一次：
```cpp
// 变量（数组替代重复分支）
int frames[2]     = {3, 3};
long lopTime[2]   = { init, init };
long fpsClock[2]  = {0, 0};

// 循环内（cam=0 或 1）
frames[cam]++; fpsClock[cam]++;
if (fpsClock[cam] >= 30) {
    long now = time.tv_sec * 1000 + time.tv_usec / 1000;
    printf("Cam%d FPS: %.1f (30帧耗时 %.1fms)\n", cam, 30000.0f / (now - lopTime[cam]), (float)(now - lopTime[cam]));
    lopTime[cam] = now; fpsClock[cam] = 0;
}
```

单流模式同步简化：
```cpp
if (frames % 30 == 0) {
    printf("FPS: %.1f (30帧耗时 %.1fms)\n", 30000.0f / (tmpTime - lopTime), (float)(tmpTime - lopTime));
    lopTime = tmpTime;
}
```

**效果示例：**
```
Cam0 FPS: 25.0 (30帧耗时 1200.0ms)
Cam1 FPS: 24.8 (30帧耗时 1210.0ms)
```

### 3. 双摄同时打开：线程池异步流水线

**文件：**
- `run.sh` — dual 分支参数解析
- `src/main.cc` — 双摄主循环
- `include/rknnPool.hpp` — `rknn_lite` 类（含摄像头归属 slot 标记）

**问题：** RKNN 推理耗时较长（约 40ms/帧），单线程串行处理两路摄像头会导致帧率严重下降，无法同时以正常帧率运行两路。

**方案：** 6-slot 线程池流水线，Cam0 占 slot 0/1/2，Cam1 占 slot 3/4/5。

**关键实现：**

`main.cc` — 参数解析识别 `dual` 模式：
```cpp
bool dual_cam = false;
if (strcmp(argv[1], "dual") == 0) dual_cam = true;
```

`run.sh` — 输入输出地址用逗号分隔，`camera` / `camera2` 自动映射为 `/dev/video0` / `/dev/video2`：
```sh
dual)
    CAM0="${4:-camera}"    # 默认 /dev/video0
    CAM1="${5:-camera2}"    # 默认 /dev/video2
    if [[ "$CAM0" == "camera" ]]; then  CAM0="/dev/video0"; fi
    if [[ "$CAM1" == "camera2" ]]; then CAM1="/dev/video2"; fi
    # 单 RTSP URL 自动派生第二个（cam0 → cam1）
```

`main.cc` — 主循环采用固定 6 future 槽位轮询，不新开线程：
```cpp
std::future<int> slots[6];
while (true) {
    for (int i = 0; i < 6; i++) {
        if (slots[i].wait_for(0ms) == ready) {
            slots[i].get();
            int cam = (i < 3) ? 0 : 1;           // 0~2 是 Cam0，3~5 是 Cam1
            cv::VideoCapture& c = (cam == 0) ? cap : cap1;
            c.read(frame);
            frame.copyTo(rkpool[i]->ori_img);
            slots[i] = pool.submit(&rknn_lite::interf, rkpool[i]);
        }
    }
}
```

`rknnPool.hpp` — 每个 `rknn_lite` 实例绑定固定 NPU 核心（`core_id % 3`），6 个实例轮转使用 RKNN 3 个物理核心：
```cpp
switch (core_id % 3) {
    case 0: core_mask = RKNN_NPU_CORE_0; break;
    case 1: core_mask = RKNN_NPU_CORE_1; break;
    default: core_mask = RKNN_NPU_CORE_2;
}
rknn_set_core_mask(ctx, core_mask);
```

**架构总结：**

```
Cam0 (VideoCapture) ──┐
                      ├── 读帧 ──→ ori_img ──→ 线程池 submit ──→ interf() ──→ imshow/push
Cam1 (VideoCapture) ─┘

线程池 6 slots：   [S0(core0)] [S1(core1)] [S2(core2)] [S3(core0)] [S4(core1)] [S5(core2)]
摄像头归属：        Cam0        Cam0        Cam0        Cam1        Cam1        Cam1
```

### 4. MQ-2 烟雾传感器读取

**文件：** `Hardware/ads1115/mq-2/mq2_read.cpp`

**硬件接线（ADS1115 AIN0）：**
```
5V ──┬── MQ-2 (Rs) ──┬── AIN0 ── ADS1115
     │               │
     └─── 10kΩ ─────┘
```

**原理：**
- ADS1115 单端读取 AIN0，量程 ±4.096V，128 SPS
- 电压分压公式：`Rs = RL × (VCC − Vout) / Vout`（RL = 10kΩ，VCC = 5V）
- Ro（清洁空气基准电阻）首次测量自动标定，后续以 ratio = Rs/Ro 换算浓度

**编译运行：**
```bash
cd Hardware/ads1115/mq-2
g++ -std=c++17 -O2 -Wall mq2_read.cpp -o mq2_read -lm
sudo ./mq2_read
```

**输出内容：**
- `V`：AIN0 实测电压 (V)
- `Ro`：清洁空气基准电阻 (Ω)
- `Rs`：当前传感器电阻 (Ω)
- `ratio`：Rs/Ro，比值越小浓度越高
- `LPG ppm`：LPG 气体估算浓度（仅供参考）
- `smoke %`：相对烟雾浓度 0~100%
- `[Safe / Low / Warn / DANGER]`：四级警报
