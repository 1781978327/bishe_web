```bash

cmake ..
```

## 运行

### 快速启动（使用 run.sh）

```bash
cd /home/orangepi/sheji/yolov8-rk3588-cpp-inference-main
bash run.sh
```

`run.sh` 已配置好所有环境变量和参数，直接运行即可。

## 参数说明

```
./build/rknn_yolov8_demo <yolov8模型> <视频源> <输出路径> <Re-ID模型>
```

| 参数 | 说明 | 示例 |
|------|------|------|
| 1. yolov8模型 | 模型路径 | `install/model/RK3588/yolov8s.rknn` |
| 2. 视频源 | 视频文件路径、`0`（摄像头）或 `/dev/video0` | `video/person.mp4` 或 `0` |
| 3. 输出路径 | RTSP 地址或不填（仅显示窗口） | `rtsp://ip:8554/stream` 或留空 |
| 4. Re-ID模型 | DeepSort 跟踪所需的 Re-ID 模型路径，留空则不启用跟踪 | `install/model/RK3588/osnet_x0_25_market.rknn` |

## 常见用法

### 1. 只检测，不跟踪，不保存

```bash
./build/rknn_yolov8_demo install/model/RK3588/yolov8s.rknn video/person.mp4
```

### 2. 检测 + DeepSort 跟踪（推荐）

```bash
./build/rknn_yolov8_demo install/model/RK3588/yolov8s.rknn video/person.mp4 "" install/model/RK3588/osnet_x0_25_market.rknn
```

> 第3个参数为空字符串，表示不写输出文件，只显示窗口。

### 3. 摄像头 + 跟踪

```bash
./build/rknn_yolov8_demo install/model/RK3588/yolov8s.rknn 0 "" install/model/RK3588/osnet_x0_25_market.rknn
```

### 4. RTSP 推流（需要编译时开启 RTSP_MPP）

```bash
./build/rknn_yolov8_demo install/model/RK3588/yolov8s.rknn 0 rtsp://ip:8554/stream install/model/RK3588/osnet_x0_25_market.rknn
```

## 配置：哪些类别显示 / 隐藏

### 工作原理

每个模型同目录下的 `classes.yaml` 控制显示行为：

```yaml
classes:
  - name: person
    visible: true    # 显示此类别
  - name: car
    visible: false   # 隐藏此类别
```

- `visible: true` — 绘制检测框 + 标签 + DeepSort 轨迹线
- `visible: false` — DeepSort 仍然跟踪该目标，但不在画面上绘制

### 使用 COCO 模型（80 类）只显示人

已配置好：
- 模型：`model/RK3588/yolov8s.rknn`（通用 COCO 模型）
- 配置：`install/model/RK3588/classes.yaml`（person 显示，其余 79 类隐藏）

直接运行即可。

### 自定义模型（如摔倒检测）

模型：`model/RK3588/行人摔倒打架持刀_classes.yaml`

配置示例：
```yaml
classes:
  - name: person
    visible: false   # 不显示人
  - name: fall
    visible: true    # 只显示摔倒
```

## 环境变量（run.sh 已配置）

| 变量 | 作用 |
|------|------|
| `LD_LIBRARY_PATH` | 指向 `build/lib` 和 `opencv_deps` |
| `LD_PRELOAD` | 强制使用带 FFmpeg 支持的 OpenCV videoio 库，解决视频解码问题 |

> 无需手动设置，运行 `bash run.sh` 自动生效。

## 视频解码问题说明

OpenCV 官方库编译时静默链接了静态 `.a` 库导致 FFmpeg 支持失效。

**修复方式**：`LD_PRELOAD` 注入带 FFmpeg 支持的重建版 `libopencv_videoio.so.408`。

`run.sh` 已保留此配置，无需手动干预。
